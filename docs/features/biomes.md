# Рівні та біоми

> **Статус:** Draft · **Власник:** TBD · **Оновлено:** 2026-11-15

## Навіщо
Різноманіття забігів: кожен біом змушує по-іншому будувати маршрут і пріоритети.

## Як працює
- Генерація: `Manual (Button)` — кнопкою, `Every Level Start` — автоматично на кожному BeginPlay. План тимчасовий, у мапі не зберігається.
- Біом: `Selected Config` або `Random` зі списку `RandomBiomeConfigs` з відповідними таблицями ассетів. `RandomizeSeed` дає новий seed при кожній генерації; інакше використовується seed конфігу. Джерельний DataAsset не змінюється.
- Рівень = проліт через один біом. Після нього — [безпечна зона](safe-zone.md).
- Рівень — **коридор** від старту до фінішу. Уздовж обох країв коридору чергують ракетні кулі (`BP_RocketBalloon`): виліт за край = обстріл.
- Кожен біом має свої перешкоди і небезпеки.
- На всіх рівнях є ресурси для [граплінг-хука](grappling-hook.md) (точки луту на високих спорудах).
- Набір біомів відповідає наявним ассетам (`/Game/Assets/Locations/<Level>`).

## Біоми
| Біом | Перешкоди | Особливі небезпеки |
| --- | --- | --- |
| Ліс (`Forest`) | Високі сосни, пожежна вежа; на горизонті кільце гір | — |
| Поле (`Field`) | Майже немає природних перешкод; вітряки | Птахи (зграї) — уникати або збивати |
| Місто (`City`) | Високі будинки, церква, годинникова вежа, фабрики | Туман; глушилки радара (збити тарілку) + мініігра для відновлення радара |
| Пустеля (`Desert`) | Столові гори, скельні стовпи, вежі з турелями | Піщані бурі (періодичні); маяки: якщо світло впало на кулю — викликають додаткових ворогів (уникати світла або розбити лампу) |
