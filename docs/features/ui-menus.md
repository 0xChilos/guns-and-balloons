# UI, меню і навігаційна панель

> **Статус:** Draft · **Власник:** Ростік · **Оновлено:** 2026-11-13

## Навіщо
Мінімум недієгетичного інтерфейсу. Під час гри інформація — з приладів у корзині.

## Головне меню
| Пункт | Дія |
| --- | --- |
| Continue | Продовжити останній забіг |
| New Game | Новий забіг |
| Settings | Налаштування |
| Credits | Автори |
| Legacy | TBD (прогрес між забігами?) |
| Leave | Вихід з гри |

## Навігаційна панель (в корзині)
Панель перед гравцем, через яку йде [керування кулею](balloon-controls.md). Потенційний вміст:
- керування швидкістю;
- радар (у біомі «Місто» глушиться, див. [islands.md](islands.md));
- індикатор відстані до дирижабля.
